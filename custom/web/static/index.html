第一次使用？按顺序做三步就好

只需要一个大模型 API Key，其他全部自动完成。

第 1 步 · 检查环境

看看本地组件是否齐全

检测中...

第 2 步 · 填写大模型 API Key

任选一家，都是按量计费，日常用几块钱。

第 3 步 · 开始用

配置完成后，切到「导入试卷」页签即可

导入试卷到知识库

填写服务器上的文件夹路径，程序会扫描并建立索引。

关于视觉增强：数学试卷里的公式往往是图片，普通导入会导致公式丢失。 开启视觉增强后，程序会用视觉模型把图片转成 LaTeX 文字，检索时就能命中公式内容。
先用视觉模型把图片转成文字（推荐数学卷开启）

基于知识库出题

指定知识点，AI 会从知识库里检索相关内容并生成题目。

出题需要 1-3 分钟，结果会显示在日志页
