第一次使用？按顺序做三步就好

只需要一个 MiMo API Key，其他全部自动完成。

第 1 步 · 检查环境

看看本地组件是否齐全

第 2 步 · 填写 MiMo API Key

还没有？去 小米开放平台 注册后创建（邀请码 Z7EJ2L 可领体验金）。大模型走云端，本地不用装显卡。

第 3 步 · 开始用

配置完成后，切到「导入试卷」页签即可

导入试卷到知识库

选一个文件夹，程序会自动扫描其中的文档并建立索引。

关于视觉增强：数学试卷里的公式往往是图片，普通导入会导致公式丢失。 开启视觉增强后，程序会用 MiMo 把图片转成 LaTeX 文字，检索时就能命中公式内容。
先用 MiMo 把图片转成文字（推荐数学卷开启）

基于知识库出题

指定知识点，AI 会从知识库里检索相关内容并生成题目。

出题需要 1-3 分钟，结果会显示在日志页
